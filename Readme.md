Карта регістрів `echo_ip` (базова адреса 0x44A0_0000, 32-бітні слова)

|Зміщення | Назва  Призначення |

| 0x00 | SHIFT |  [1:0] — зсув вправо
| 0x04 | DELAY |  [3:0] — затримка 
| 0x08 | CLEAR |        - обнулення
| 0x0C | SPARE | регістр для перевірки запису



## Тестові сценарії та очікувані результати

Очікувані значення (вхідний відлік плюс відлік виходу `DELAY` позицій тому, зсунутий на `SHIFT` біт), і записано в тестбенчі як константи; тестбенч порівнює кожен прийнятий вихідний біт і друкує `RESULT: PASS/FAIL`.
echo_tb.sv

1) Імпульсна характеристика, DELAY = 1, SHIFT = 1 | 10000, 0, 0, 0, 0, 0, 0 | 10000, 5000, 2500, 1250, 625, 312, 156 | кожен наступний відлік — попередній, зсунутий вправо на 2 
2) Затримка 3, SHIFT = 2 (після CLEAR) | 20000, 0, 0, 0, 0, 0, 0 | 20000, 0, 0, 5000, 0, 0, 1250 | відлуння з'являється через 3 відліки: 20000/4 = 5000, далі 5000/4 = 1250 |
3) Насичення, DELAY = 1, SHIFT = 0 | 20000, 20000, −30000, −30000, −30000 | 20000, 32767, 2767, −27233, −32768 | 20000+20000 = 40000 → 32767; −30000+32767 = 2767; 2767−30000 = −27233; −57233 → −32768
